Live AirDraw
Browser CV · Real-time

AirDraw

5 gestures · ~28 fps · 0 servers

Gesture-controlled drawing in the browser — no install, no server, no GPU; the camera feed never leaves your tab. A five-gesture vocabulary (draw, erase, lift, cycle palette, clear) runs on MediaPipe HandLandmarker entirely in WebAssembly.

  • Joint-angle finger detection — rotation-invariant and palm-size adaptive, so gestures hold as the hand turns
  • One-Euro pointer smoothing + velocity-modulated width; bitmap canvas with destination-out erase keeps render O(1)
  • Presence smoothing reuses the last frame for 180 ms, so strokes survive 1–2 dropped frames instead of breaking

About me

Engineer. Builder. Writer.

I'm a Software Engineer at ArthaVedh Consulting, building platforms in Python, Docker, and PostgreSQL where backend engineering meets DevOps — defining service boundaries, running API gateways, and keeping infrastructure dependable enough that the developers who rely on it never have to think about it. On my own time I've built three products end-to-end on yashadake.com — two live in production today — and I work in applied and agentic AI in depth.

I started there as an intern (Mar–Sep 2024), got my first production exposure to cloud infrastructure, and learned how to write Go that doesn't embarrass me a week later. Earlier experience came from LiNS (Spring Boot, JDBC), ONE IT Solutions (client-facing web work), and IEEE Bombay Section (volunteer full-stack).

Right now, I'm going deep on generative and agentic AI — not just using the APIs, but understanding how agents plan, use tools, and recover from failure. The next generation of software will be AI-native, and I intend to build parts of it.
